# 🛒 E-commerce Sales Analysis

An end-to-end E-commerce Sales Analysis project using **Python, Pandas, NumPy, MySQL, SQL, Excel, and Power BI**.

This project follows a complete data analytics workflow, starting with raw and unclean e-commerce data, cleaning and transforming it using Python, storing the cleaned data in MySQL, performing SQL analysis, and finally building an interactive Power BI dashboard.

## 🎯 Project Objective

The objective of this project is to analyze e-commerce sales data and build an interactive dashboard that provides insights into:

- Sales performance
- Profitability
- Product performance
- Category performance
- City-level sales
- Payment methods
- Order status
- Monthly sales trends

The project demonstrates the complete process of taking raw data and converting it into meaningful business insights through data cleaning, SQL analysis, and visualization.
